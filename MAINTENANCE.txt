MENGLONG DOORS & WINDOWS — STATIC WEBSITE

Open index.html in a browser, or serve this directory with any static web server.
No package installation or frontend build is required.

Pages: Home, Products, Services, Our Work, About, Team, Contact, FAQ, Privacy,
404, and Koh Reah project details. All 11 pages are available in English and Khmer.
Old template page URLs redirect to the corresponding Menglong page.

Shared page source and content: tools/build_site.py

Khmer translations: tools/km.json
Static localization renderer: tools/localize.py
English is the default at root URLs and is also available in en/. Khmer pages
are available in km/. The language switch opens the matching translated page.
Language links preserve
the current page, section and product query. Form entries are not transferred.
